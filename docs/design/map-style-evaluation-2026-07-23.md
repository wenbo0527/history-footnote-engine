## 📚 中国风地图的史实根据

### 3 个直接参考

| 古地图 | 时间 | 风格 | 史实来源 |
|---|---|---|---|
| 《嘉禾八景图》 | 元·吴镇 | 山水长卷 + 仿舆图标地名 | 台北故宫博物院藏 |
| 《西湖佳景》| 清·湖上扶摇子（1750）| 水墨山水 + 十景分图 + 序跋 | 杭州文昌阁刊印 |
| 《坤舆万国全图》 | 明万历（1602）| 李之藻绘制，山脉绵延不绝 | 中国传统舆图 + 西法结合 |
| 《明·清黄河和京杭大运河地图》 | 明清 | 山水形象画法 + "对景法" | 学术论文（地球信息科学学报）|

### 中国传统地图三要素（史实规制）

1. **山脉符号** — 宋代《禹迹图》《华夷图》起就用的"向上突起折线/小山符号"
2. **河道** — 明清规制"运河用绿色波纹，黄河用黄色波纹 + 大浪花"
3. **城池符号** — 明清规制：府/州/县城用**不同等级的方形符号**（参考《明·清·民国时期地图要素视觉表达方法分析》）

### 古代地图主流手法 — 山水形象画法

> "中国古地图符号最大特点就是**象形**。地图上的图形符号，要尽可能反映地物的外形和特征，让读者很容易联想到它所代表的地物。"—— 张寒梅等《浅析中国古地图符号表示方法》

明清水墨地图特征：
- ✅ 山脉用**披麻皴水墨**或**符号化小山**
- ✅ 河流用**弯曲曲线 + 小波纹**
- ✅ 湖泊用**鱼鳞状波纹**
- ✅ 城市用**鸟瞰式绘制**（不是图标，是写意鸟瞰）
- ✅ 文字用**楷书/小楷**（不是现代字）
- ✅ 整体像**水墨长卷**

## 🎯 推荐的 3 个中国风改造方案

### 方案 A：纯 SVG + 传统符号（推荐，1 天）

**保留现有 SVG 架构**，但用**传统中国地图符号**重新绘制：

```
┌─ 改造元素 ──────────────────────────────────┐
│  山脉     折线小山符号（ΛΛΛΛΛ）+ 水墨笔触     │
│  河流     青色曲线 + 鱼鳞波纹装饰              │
│  湖泊     鱼鳞波纹 + 蓝色渐变                  │
│  城市     方形城墙符号（带"府/州/县"字样）      │
│  道路     黄底红条纹（明清规制）                │
│  标注     楷书字体（web font: KaiTi / STKaiti）│
│  背景     米黄色宣纸纹理                       │
│  整体     长卷式 + 计里画方网格                 │
└──────────────────────────────────────────────┘
```

**工作量**：1-2 天（纯前端，重写 SVG 部分）

**优点**：
- 不依赖外部图片资源
- 完全程序化生成（跟现有架构一致）
- 渲染快 + 史实保证

**缺点**：
- SVG 山水画法难精到（vs 真实水墨画）

### 方案 B：水墨长卷背景 + 现代符号（3 天）

**用程序化生成的水墨长卷图**（CanvasTexture 渐变 + 山形符号），然后：
- 前景 = 传统符号（跟方案 A）
- 背景 = 长卷山水画风
- 玩家路径 = 朱砂笔触（明代漆器红）

**工作量**：3-4 天

**优点**：
- 视觉上最像古代舆图
- 程序化生成的"长卷"很贴近宋代《嘉禾八景图》

**缺点**：
- CanvasTexture 性能开销
- 跟现有 hd2d_demo 的程序化纹理可复用

### 方案 C：拼装古代舆图截图 + 现代叠加（5 天）

**用现成的明清地图元素**（从公有领域图片库）：
- 大英图书馆藏 100+ 张中国古地图（1800s 前）
- Library of Congress / Harvard-Yenching 馆藏
- 北京故宫博物院 / 台北故宫博物院

**叠加现代元素**：城市圆点 + 路径 + 当前地点标

**工作量**：5-7 天（找资源 + 拼接 + 标注图层）

**优点**：
- 最真实的"古代舆图感"
- 史实保证 100%（本身就是古地图）

**缺点**：
- 资源获取 + 法律风险（公有领域确认）
- 跟游戏 UI 风格难统一（古地图是写实鸟瞰，游戏是叙事）

## 🎯 我的推荐

**方案 A + 部分方案 B**（混合方案）：

### 第一阶段（1-2 天，纯 SVG 改造）
- 山脉 → 小山符号
- 河流 → 鱼鳞波纹
- 湖泊 → 鱼鳞波纹
- 城市 → 方形城墙符号
- 道路 → 黄底红条纹
- 字体 → 楷书
- 背景 → 宣纸纹理

### 第二阶段（2-3 天，水墨长卷背景）
- CanvasTexture 生成水墨山水底图
- 远山 → 披麻皴笔触（程序化）
- 近景 → 江南水乡（白墙灰瓦程序化简笔）
- 朱砂笔触玩家路径

### 关键约束

**保持简单**：游戏是文字叙事，地图是导航工具，**不需要 Octopath 全 3D 风格**。
**史实保证**：所有地图符号都是明清规制，跟万历年间历史一致。
**性能**：SVG < 10KB，CanvasTexture < 1MB，移动端 60fps。
